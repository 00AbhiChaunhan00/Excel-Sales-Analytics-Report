# 📊 Excel Sales Analytics Report

> A comprehensive Sales Analytics Reporting project built in **Microsoft Excel** to analyze business performance through professional management reports. This project focuses on transforming raw sales data into meaningful insights for decision-makers using Excel's advanced reporting capabilities.

---

## 📌 Project Overview

This repository contains multiple business reports created using Microsoft Excel for analyzing sales performance from different perspectives such as customers, markets, fiscal years, and monthly profitability.

---

# 📁 Reports Included

| Report | Description |
|---------|-------------|
| 📈 Customer Performance Report | Analyze customer-wise sales performance across multiple years. |
| 🌍 Market Performance vs Target Report | Compare actual market sales against predefined targets |
| 💰 Profit & Loss Statement by Fiscal Year | Evaluate yearly profit and loss performance. |
| 🌎 Profit & Loss Statement by Markets | Analyze profitability across different markets. |
| 📅 Profit & Loss Statement by Months | Track monthly financial performance and trends. |
